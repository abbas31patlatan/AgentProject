# Game playbook template

## 1. Boot and first launch

Document exactly what appears from process start until the main menu. Include language selectors, EULAs, tutorials, login prompts, and safe defaults.

## 2. Start or resume

Explain how to resume a known save and how to start a disposable test game. State which choice is non-destructive.

## 3. Observation checklist

Before every meaningful action, record what the agent must inspect: current objective, resources, selected entity, alerts, modal dialogs, minimap, timers, turn state, health/status and any other critical UI.

## 4. Control map

Describe mouse buttons, keyboard controls, camera movement, zoom, drag operations and how to cancel a mistaken selection.

## 5. How the game is played

Explain the objective, important resources, progression system, loss conditions and the decision loop. Prefer actionable rules over encyclopedic detail.

## 6. Decision cycle

Define one complete loop:

1. Observe.
2. Identify mandatory decisions.
3. Choose a reversible action when uncertain.
4. Execute.
5. Observe again and verify the expected UI/state change.
6. Save or reach the safe pause point.

## 7. Save and recovery

Document save paths, autosave behavior, manual save procedure and how to resume after a crash.

## 8. Dangerous or irreversible operations

List actions that must not be taken blindly. Include save deletion/overwrite and any external account or real-money action.

## 9. Success checks

Explain how the agent can visually or structurally verify that moves, purchases, builds, dialogue choices or turn transitions actually happened.

## 10. Known quirks

Record resolution-sensitive UI, animation delays, popups, tutorials and other behavior learned during real play.
